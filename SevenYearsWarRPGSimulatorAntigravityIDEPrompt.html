Antigravity IDE Master Prompt & Architecture Specification: 1756 Seven Years' War Simulator

1. Executive System Overview

Build a full-stack web application simulating the 1756 Seven Years' War across the Americas and the Caribbean (10°N–55°N, 55°W–100°W). The platform combines a turn-based macro-engine, asynchronous courier communication, relational event sourcing with deterministic SQL invalidation, and role-based player seating (Human vs. AI: Advisor or Autonomous).

Core Design Constraints:

  • Geography: Map strictly bounded to North America and the Caribbean. Off-map theaters (Europe, India, West Africa) affect the game via abstract state modifiers.
  • Factions (10):
  • European Powers: Great Britain, France, Spain, Portugal, Dutch Republic, German States (Prussia/Austria representation).
  • Native American Confederations: Haudenosaunee, Seven Nations of Canada, Western Confederacy, Southeastern Nations.
  • Roles: 3 distinct seats per faction (Executive, Military, Commercial/Logistics).
  • AI Seating: Configurable in Admin as Human or Computer (Advisor mode: strategic recommendations; Autonomous mode: JSON order execution).
  • Token Efficiency: Constant O(1) context budget (~1,500–2,000 tokens per character turn) achieved via database ground-truth queries, rolling summary buffers, and temporal SQL event invalidation.

2. Technical Stack Specification

  • Frontend: Next.js (App Router), Tailwind CSS, Lucide React, Zustand (Client State), Leaflet / React-Leaflet.
  • Backend: Next.js Server Actions / Route Handlers, Prisma ORM.
  • Database: PostgreSQL (Relational tables, JSONB fields, temporal event tracking), Redis (Courier queues and turn scheduling).
  • AI Engine: DeepSeek API (Base URL: https://api.deepseek.com), utilizing a hybrid deployment of deepseek-v4-pro (for high-level executive strategic reasoning) and deepseek-flash (for fast, schema-strict tactical orders and advisor briefings).

4. Deterministic Event Invalidation Service (engine/events/reconciler.ts)

Implement deterministic SQL event nullification so the AI and human dashboards only retrieve valid, active historical data:import { PrismaClient, EventStatus } from "@prisma/client";

const prisma = new PrismaClient();

export async function recordAndReconcileEvent(params: {

  gameId: string;

  turn: number;

  category: string;

  scope: any;

  primaryNodeId?: string;

  factionIds: string[];

  title: string;

  description: string;

  validUntilTurn?: number;

}) {

  return await prisma.$transaction(async (tx) => {

    // 1. Create the new event

    const newEvent = await tx.gameEvent.create({

      data: {

        gameId: params.gameId,

        turnRecorded: params.turn,

        category: params.category,

        scope: params.scope,

        primaryNodeId: params.primaryNodeId,

        factionIds: params.factionIds,

        title: params.title,

        description: params.description,

        validUntilTurn: params.validUntilTurn,

        status: EventStatus.ACTIVE,

      },

    });

    // 2. Rule: Treaty/Peace supersedes prior war declarations between parties

    if (params.category === "TREATY") {

      await tx.gameEvent.updateMany({

        where: {

          gameId: params.gameId,

          status: EventStatus.ACTIVE,

          category: "WAR_DECLARATION",

          factionIds: { hasEvery: params.factionIds },

        },

        data: {

          status: EventStatus.SUPERSEDED,

          supersededById: newEvent.id,

        },

      });

    }

    // 3. Rule: Fort capture supersedes prior garrisons and blockades on that node

    if (params.category === "FORT_CAPTURED" && params.primaryNodeId) {

      await tx.gameEvent.updateMany({

        where: {

          gameId: params.gameId,

          primaryNodeId: params.primaryNodeId,

          status: EventStatus.ACTIVE,

          category: { in: ["GARRISON", "SIEGE_ORDER", "BLOCKADE"] },

        },

        data: {

          status: EventStatus.SUPERSEDED,

          supersededById: newEvent.id,

        },

      });

    }

    return newEvent;

  });

}

export async function expireTurnEvents(gameId: string, currentTurn: number) {

  await prisma.gameEvent.updateMany({

    where: {

      gameId,

      status: EventStatus.ACTIVE,

      validUntilTurn: { lt: currentTurn },

    },

    data: {

      status: EventStatus.EXPIRED,

    },

  });

}

5. Token-Bounded Faction Serializer & AI Agent Architecture

Filtered Retrieval Query

export async function getRoleContextPayload(gameId: string, factionId: string, role: string) {

  const faction = await prisma.faction.findUnique({

    where: { id: factionId },

    include: {

      nodesControlled: true,

      units: { include: { node: true } },

    },

  });

  // Fetch only ACTIVE, relevant events

  const activeEvents = await prisma.gameEvent.findMany({

    where: {

      gameId,

      status: EventStatus.ACTIVE,

      OR: [

        { factionIds: { has: factionId } },

        { scope: "GLOBAL" },

      ],

    },

    orderBy: { turnRecorded: "desc" },

    take: 6, // Hard upper limit guarantees O(1) token consumption

  });

  return {

    factionState: {

      treasury: faction?.treasury,

      debt: faction?.debt,

      unrest: faction?.unrestIndex,

      points: faction?.standingPoints,

    },

    activeUnits: faction?.units.map(u => ({

      type: u.unitType,

      strength: u.strength,

      location: u.node.name,

    })),

    recentActiveEvents: activeEvents.map(e => `[Turn ${e.turnRecorded}] ${e.title}: ${e.description}`),

  };

}

Hybrid DeepSeek Model Routing Engine (app/api/ai/route.ts)

To balance strategic depth with cost and concurrency efficiency, implement a tiered model router:

  • deepseek-v4-pro (Thinking Mode Enabled): Reserved exclusively for Autonomous Executive roles (10 seats). Deliberates on grand strategy, long-term alliance viability, sovereign credit and debt limits, and multi-theater resource balancing.
  • deepseek-flash (Thinking Mode Disabled): Assigned to Autonomous Military and Commercial sub-roles (20 seats) as well as all Advisor briefings. Guarantees low latency, prevents reasoning token overhead, and strictly enforces the AutonomousOrderSchema JSON output.
